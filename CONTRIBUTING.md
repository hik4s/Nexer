# Contribuindo com o RelatPy

## Fluxo
1. Abra uma issue no Linear para a mudança.
2. Crie uma branch curta a partir de `master`.
3. Para comportamento funcional, escreva o teste antes da implementação.
4. Execute a suíte local e o pipeline do GitHub Actions.
5. Abra Pull Request com evidências.
6. Faça review antes do merge.

## Definition of Done
Uma tarefa relevante só está pronta quando implementação, testes, tratamento de erro, logs, documentação, segurança e evidência de validação estiverem atendidos.

## Commits
Use mensagens curtas e sem dados sensíveis, preferencialmente no formato `tipo: descrição`.

## Segurança
Nunca commit credenciais, tokens, cookies, arquivos de sessão, dados reais, caminhos internos sensíveis ou artefatos de execução.
